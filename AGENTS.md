# Mandatory Repository Rules & Guidelines

1. **ZERO EMOJIS OR ICONS**:
   - Never use emojis, decorative icons, or unicode symbols anywhere in code, comments, documentation, commit messages, or terminal output.
2. **STRICT ENGLISH ONLY**:
   - All source code, comments, docstrings, and documentation must be 100% English (except localization dictionaries in `i18n.ts`).
3. **COMPLETE PROVIDER NEUTRALITY**:
   - Treat all AI providers (Google Gemini, OpenAI, Anthropic Claude, Local Ollama, and custom OpenAI-compatible providers) as equal peers.
4. **NO AI BUZZWORDS**:
   - Write direct, factual technical sentences without marketing fluff.
